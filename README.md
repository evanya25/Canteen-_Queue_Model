# Canteen Pre-ordering Simulation

Discrete-event simulation comparing the existing canteen (System A)
with pre-ordering arrangements (System B).

## How to run
pip install numpy pandas scipy matplotlib
python canteen_model_two_counters.py
python make_results_table.py
